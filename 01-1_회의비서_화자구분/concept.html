Project Concept Brief

회의비서.
듣고, 정리하고, 보고서까지.

회의 음성을 받아 **요약·결정·액션·리스크**까지 자동으로 정리해 *한 장의 보고서*로 띄워주는 AI 비서. *내 PC 안에서만* 동작하고, *MCP 서버 없이* 시작합니다.

What problem? 02 / 06

어떤 문제를 풀어요?

회의 끝나면 정리하다가 *저녁에 한 시간 더 일하던 경험* — 다들 있으시죠.
3
반복 문제
문제 ①
누가, 뭘, 언제까지?
분명히 합의했는데 다음 주에 또 같은 얘기를 한다. 액션 아이템이 *말로만* 남아있기 때문.
문제 ②
회의록 정리에 1시간
실제 일하는 시간보다 *기록·정리*에 더 많은 시간이 든다. 회의 끝나면 진이 빠진다.
문제 ③
집중 vs 받아쓰기
받아쓰면서 듣다 보면 *맥락을 놓친다*. 둘 다 동시에 잘하기는 어렵다.

5 concepts you learn by building 05 / 06

핵심 개념 5가지.

만들면서 손으로 익히는 *AI 시대 기본기*.
05
Core
01
음성 → 글 (STT)
사람 말 소리 → 텍스트. 외국 영상에 자막 자동 다는 것과 같은 원리. 우리는 *로컬에서* 한다.
02
로컬 AI vs 클라우드 AI
민감 데이터(회의)는 로컬, 일반 요약은 클라우드. *둘을 영리하게 섞는 게* 실무 패턴.
03
JSON 강제 — 형식 명령
AI에게 *자유 작문* 시키면 들쭉날쭉. *빈칸 양식*을 강제하면 데이터로 자동 변환 가능.
04
템플릿 + 데이터
"제목: {title}" + {title:"주간"} = "제목: 주간". 같은 모양에 데이터만 갈아끼우는 패턴.
05
subprocess — 도구 조립
Python에서 다른 도구(claude CLI)를 부르는 *접착제*. 작은 도구들을 묶어 큰 자동화를 만든다.

실무 응용
+ Slack
팀 채널 자동 발송
회의 끝나고 5초 후 #weekly 채널에 요약 도착. 팀 전체가 같은 페이지에.

사내 위키 자동 등재
회의록이 사내 Notion에 영구 저장. 신입도 과거 모든 회의 검색 가능.
+ Gmail
메일 초안 자동 생성
다음 회의 안내 메일이 초안함에 미리 와있음. 사람은 *검수만* 한다.
+ Calendar
액션 → 일정 자동 등록
"5월 27일까지 ROI 분석" → 캘린더에 마감 알림이 자동으로.
