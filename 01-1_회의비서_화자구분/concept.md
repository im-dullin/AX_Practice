# 회의비서 — 프로젝트 개념 한눈에 보기

> **한 줄 정의**: 회의 음성을 듣고, **요약·결정사항·할 일·리스크**까지 자동으로 정리해 한 장의 보고서로 띄워주는 *AI 비서*.

---

## 1. 어떤 문제를 풀어요?

직장에서 회의 끝나면 항상 이런 일이 반복돼요:
- 누가 무엇을 언제까지 한다고 했더라?
- 분명히 결정했는데 다음 주에 또 같은 얘기를 한다
- 회의록 정리하려고 *저녁에 한 시간 더 일함*

이 프로젝트는 **회의 중에는 100% 집중하고, 끝나면 보고서가 손에 들려 있게** 만듭니다.

---

## 2. 어떻게 동작해요? — 손으로 그려보는 흐름

```
   [내가 말한다]
        │  🎤 마이크 녹음 (sounddevice)
        ▼
   📁 recording.wav 파일이 저장됨
        │
        ▼
   🤖 Whisper AI가 음성을 듣고 한국어 텍스트로 변환
        │  "이대리: 이번 주 신규 리드는 32건이고..."
        ▼
   🧠 Claude가 텍스트를 읽고 7개 영역으로 분류
        │  요약 · 액션 · 결정 · 리스크 ...
        ▼
   🎨 예쁜 HTML 보고서로 변신
        │
        ▼
   🌐 브라우저가 자동으로 띄워줌 → 끝!
```

**전체 5단계 — 사람이 손대는 건 "녹음 시작·종료" 뿐.**

---

## 3. 어떤 부품으로 만들어졌나요?

비유로 이해하기:

| 부품 | 비유 | 무엇을 해요 |
|---|---|---|
| **sounddevice** | 녹음기 | PC 마이크에서 소리를 받아 파일로 저장 |
| **soundfile** | 카세트테이프 | 받은 소리를 `.wav` 라는 표준 음성 파일로 굳혀줌 |
| **faster-whisper** | 통역사 | 한국어를 듣고 글자로 받아 적는 AI (OpenAI Whisper의 *고속 버전*) |
| **Claude Code CLI** | 회의록 정리해주는 동료 | "이걸 7개 영역으로 정리해줘" 한 마디로 끝 |
| **Python 표준 라이브러리** | 종이와 펜 | 받은 결과를 HTML 모양으로 인쇄 |

모두 **무료 · 오픈소스 · 내 컴퓨터 안에서만** 동작합니다. 회의 내용이 외부로 새지 않아요.

## 4. 핵심 개념 5가지 — 만들면서 배우는 것

### ① 음성을 글로 (STT, Speech-to-Text)
사람이 말하는 *소리 파동*을 AI가 듣고 *글자*로 받아 적는 기술. 우리가 쓰는 `faster-whisper`는 OpenAI가 만든 *Whisper* 모델의 빠른 버전. **인터넷 없이도 작동**합니다.

> 비유 — 외국어 영상에 자막이 자동으로 달리는 거랑 같은 원리.

### ② 로컬 AI vs 클라우드 AI
- **로컬 AI** (회의비서의 Whisper): 내 PC에서만 동작. 데이터 외부 X. 단점은 PC 성능 의존.
- **클라우드 AI** (ChatGPT, Claude): 인터넷 너머 서버에서 동작. 빠르지만 데이터가 외부로 나감.

> 회의 같은 *민감한 자료*는 로컬 STT, 일반 *요약·분류*는 클라우드. 우리 프로젝트는 *둘을 영리하게 섞은* 구조.

### ③ JSON 강제 — AI에게 *형식 명령*하는 법
"요약 좀 해줘" 라고 하면 AI는 매번 다른 모양으로 답해요. 우리는 프롬프트에:
```json
{
  "summary": "...",
  "decisions": [...],
  "actions": [{"owner": "...", "task": "...", "due": "..."}]
}
```
이 모양으로 **반드시** 답하라고 *강제*합니다. 그래야 다음 단계(HTML 만들기)에서 안정적으로 처리할 수 있어요.

> 비유 — 신청서 양식. *자유 작문*은 정리하기 어렵지만 *빈칸 양식*은 데이터화 쉬움.

### ④ HTML 템플릿 + 데이터 결합
요약 결과(JSON)와 *템플릿*(빈칸 있는 HTML)을 합쳐 *완성된 보고서*가 나옵니다. 이걸 **템플릿 엔진**이라고 해요.

```
"제목: {title}"  +  {"title": "주간회의"}  =  "제목: 주간회의"
```

> 비유 — 회사 명함 디자인은 한 번만, 사람마다 이름·연락처만 채우면 끝.

### ⑤ subprocess — Python이 다른 프로그램 부르기
Python 코드 안에서 *터미널 명령어*(`claude -p ...`)를 실행하고 결과를 받아오는 기술. *서로 다른 도구를 조립*해 더 큰 일을 하게 해주는 *접착제*.

> 비유 — 청소 로봇 + 자동 잠금 도어. 둘 다 만든 사람이 다르지만 *내 집에서는 같이 동작*하게 묶을 수 있음.

## 5. 응용 — *내 회사*에 어떻게 가져가나요?

이 프로젝트의 *출력 단*만 갈아끼우면 곧바로 실무 도구가 됩니다:

| 출력 변경 | 결과 | 누구에게 좋아요 |
|---|---|---|
| HTML → **Slack 채널 발송** | 회의 끝나면 5초 후 #weekly 채널에 요약 도착 | 팀 전체 |
| HTML → **Notion DB 자동 등재** | 회의록이 사내 위키에 영구 저장 | 회사 전체 |
| HTML → **메일 초안 (Gmail)** | 다음 회의 안내메일이 초안함에 미리 와있음 | 미팅 호스트 |
| HTML → **캘린더 일정 자동 등록** | 액션 아이템마다 캘린더 알림이 자동 | 본인 |

**30일 로드맵 Week 1 미션** — 이 출력 단 하나만 자기 회사 메신저로 바꿔보기.

## 6. 이 프로젝트로 *배워서 가는* 것

수업이 끝나면 여러분은:

- ✅ AI에게 *형식을 강제*하는 프롬프트 작성법
- ✅ *민감한 데이터*를 외부로 보내지 않고 처리하는 *로컬 AI* 사용법
- ✅ *여러 도구를 조립*해 한 흐름으로 묶는 Python 패턴
- ✅ *예쁜 결과물*을 자동으로 만드는 HTML 템플릿 활용법
- ✅ *내 손으로* 만든 첫 자동화 도구 — *내일부터 회의에 쓸 수 있는*
