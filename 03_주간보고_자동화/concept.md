# 주간보고 자동화 — 프로젝트 개념 한눈에 보기

> **한 줄 정의**: Notion에 *일별 메모*만 적어두면, 일요일 밤 5초 만에 *7섹션 구조화된 주간 보고서*가 자동으로 만들어지는 *AI 비서*.

> ★ **이 프로젝트의 학습 포인트**: 카드뉴스에서 *MCP 서버*를 썼다면, 이번엔 **REST API를 직접 호출**합니다. 둘을 *비교 학습*하는 것이 핵심.

---

## 1. 어떤 문제를 풀어요?

직장인의 *주간 보고서* — 모두가 하지만 모두가 미루는 일:

- 일요일 밤마다 *한 시간 반* — *이번 주에 뭐 했지...* 기억 재구성
- 정작 *결정사항·다음 주 계획·리스크*는 매번 빠뜨림
- 보고서마다 *형식이 들쭉날쭉* — 보는 사람도 피곤

이 프로젝트의 슬로건:

> **"월요일 1시간 30분 → 일요일 밤 5초"**

평일에는 *Notion에 일별 토글 메모 한 줄씩*만 적어두세요. 일요일에 URL 입력 한 번으로 *완성된 보고서*가 나옵니다.

---

## 2. 어떻게 동작해요?

```
   [월~금: Notion에 일별 메모]
        │  ✏️ 토글 안에 자유롭게 (불릿/체크박스/표 다 OK)
        ▼
   [일요일 밤: URL 입력]
        │  🌐 http://localhost:5000 에서 Notion 페이지 URL 붙여넣기
        ▼
   📡 Notion REST API 직접 호출 → 페이지 fetch
        │  ★ 여기가 MCP와의 비교 포인트!
        ▼
   🔍 이번 주(월~일) 토글만 필터링
        │
        ▼
   🧠 Claude가 7섹션 JSON 으로 구조화
        │  BEFORE · PROGRESS · DECISIONS · LESSONS · NEXT · ASKS · RISKS
        ▼
   🎨 Jinja2 HTML 템플릿 + 데이터 결합
        │
        ▼
   🌐 브라우저 자동 오픈 + output/ 폴더에 영구 저장
```

**전체 7단계 — 사람은 *평일 메모*와 *일요일 URL 입력*만.**

## 3. 부품 비유

| 부품 | 비유 | 무엇을 해요 |
|---|---|---|
| **Flask** | 식당 카운터 | 웹 폼 + 결과 페이지 |
| **requests** | 배달원 | Notion 서버에 *직접 가서* 페이지 받아옴 |
| **Notion REST API** | Notion이 외부에 공개한 *창구* | 페이지 정보를 *표준 JSON*으로 응답 |
| **python-dotenv** | 비밀 금고 | API 토큰을 코드 밖 `.env` 파일에 보관 |
| **Claude Code CLI** | 보고서 정리 전문가 | 일별 메모 → 7섹션 구조화 |
| **Jinja2** | 인쇄 양식 | 데이터를 HTML 보고서로 찍어냄 |

## 4. ★ 핵심 개념 — *MCP* vs *REST API 직접*

이 프로젝트의 *진짜 학습 포인트*. 카드뉴스에서 본 *MCP 서버*와 비교해 보세요.

### 카드뉴스 (Project ②) — MCP 서버 사용

```python
# 한 줄
subprocess.run([
    "claude", "-p", "이 URL 가져와줘",
    "--allowedTools", "mcp__firecrawl__firecrawl_scrape"
])
```

→ Claude가 알아서 Firecrawl 호출 → 결과 반환. *우리 코드*에는 Firecrawl 관련 로직 0.

### 주간보고 (Project ③) — REST API 직접

```python
# 여러 줄
import requests
headers = {
    "Authorization": f"Bearer {NOTION_TOKEN}",
    "Notion-Version": "2022-06-28"
}
response = requests.get(
    f"https://api.notion.com/v1/blocks/{page_id}/children",
    headers=headers
)
data = response.json()
# 재귀적으로 토글 안의 블록 fetch
# 에러 핸들링
# 페이지네이션 처리
# ...
```

→ *우리 코드*가 Notion API를 직접 다룸. 토큰 관리·요청 만들기·응답 파싱 전부.

### 둘 중 뭐가 더 좋은가?

**상황에 따라 다름**:

| 기준 | MCP 서버 | REST API 직접 |
|---|---|---|
| **코드 양** | 1줄 | 50줄+ |
| **응답 속도** | 1~3초 | 0.1초 |
| **API 한도 관리** | MCP 서버가 처리 | 직접 처리 |
| **세밀한 제어** | 제한적 | 완전 자유 |
| **버그 발생 시** | Claude + MCP 로그 둘 다 봐야 | 코드 한 곳만 보면 됨 |
| **유지보수** | MCP 서버가 업데이트 | API 변경되면 코드 수정 |

**결론**: *간단한 일회성·여러 AI에서 공유*는 MCP. *세밀한 제어·대량 호출·속도 중요*는 REST 직접. **둘 다 알아야 옳게 쓴다.**

## 5. 핵심 개념 5가지 — 만들면서 배우는 것

### ① REST API 직접 호출 ★
HTTP로 외부 서비스에 *직접 요청*을 보내고 *JSON*으로 응답을 받는 패턴. **인터넷의 가장 기본**. requests 라이브러리로 한 줄.

> 비유 — 식당에 *직접 전화*해서 주문. (MCP는 *배달앱*을 통한 주문)

### ② 인증 토큰 (.env 파일)
Notion API를 쓰려면 *내 계정임을 증명*하는 토큰 필요. 이걸 코드에 박지 않고 `.env` 파일에 보관 + `python-dotenv`로 로드. **보안 기본기**.

> 비유 — 금고 비밀번호를 메모지에 쓰면 안 되듯, 토큰도 코드에 쓰면 안 됨.

### ③ JSON 응답 파싱 + 재귀 처리
Notion 페이지는 *블록 안에 블록*이 들어있는 *나무 구조*. 토글 안에 표가 있고, 표 안에 또 텍스트가... 이걸 *재귀 함수*로 모두 끄집어내기.

> 비유 — 러시아 인형 *마트료시카*. 안에 또 인형, 또 인형. 다 꺼내려면 *같은 동작*을 반복.

### ④ Jinja2 — 더 강력한 HTML 템플릿
회의비서의 `str.format`보다 표현력 좋은 *진짜 템플릿 엔진*. `{% for %}` 반복문, `{% if %}` 분기, 필터 등 사용 가능.

> Flask가 *기본 탑재*하는 표준 라이브러리. 한 번 배우면 어디서나 쓰임.

### ⑤ AI 가드레일 — *환각 방지*
Claude에게 *"원문에 없는 사실은 절대 만들지 마라"* 명시. 모호하면 `(확인 필요)` 라벨 붙이게. **회사 보고서엔 사실 정확성이 생명**.

> 비유 — 자율주행차에 *"확신 없으면 멈춰"* 룰 박는 것. 그래야 신뢰할 수 있음.

## 6. AI 의견 + 원문 가드레일 = *신뢰할 수 있는 자동화*

이 프로젝트의 *진짜 가치*는 **AI의 정리 능력 + 사실 보호 가드레일** 결합:

| 영역 | AI에 맡김 | 사람이 통제 |
|---|---|---|
| **그루핑** | 비슷한 메모 묶어 7섹션 분류 | — |
| **활동 vs 결과 구분** | "참여함" → "참여해서 X 결정" | — |
| **인사이트 생성** | LESSONS 섹션 자동 작성 | — |
| **원문 사실** | 절대 변경 X | ✅ 가드레일로 강제 |
| **모호한 부분** | "(확인 필요)" 라벨 | ✅ 사람이 검수 |
| **최종 승인** | — | ✅ 사람이 발송 전 1차 검토 |

이게 **L3 (Execute on Approval)** 자동화 — *AI가 초안, 사람이 승인*. 실무에서 가장 안전하고 가장 자주 쓰는 패턴.
